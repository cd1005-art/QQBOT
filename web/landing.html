用官方能力做群管理
不靠协议端，不模拟客户端

QQ 官方机器人的 Webhook 接入、事件落库、规则自动处置、定时任务与操作审计，打包成一个可自托管的小控制台。

打开控制台 查看文档
Python 标准库 SQLite 无前端构建 MIT

能做什么

全部走 QQ 开放平台官方接口，能力边界与平台权限一致

全量群消息

开启「获取群内全部消息」后，连非 @ 消息一起收，落库可查。

撤回 / 禁言 / 解禁

按消息逐条撤回，按成员禁言到分钟，全员禁言一键开关。

规则自动处置

关键词或正则命中，自动撤回、禁言或两者并行，按群生效。

定时任务

5 段 cron，到点向指定群发消息，执行结果留痕可追。

事件与审计

原始事件按类型留档，写操作逐条记录，可导出 CSV。

两道安全闸

dry_run 硬锁 + 群白名单，改配置才放行真实操作。

运行方式

单进程双端口，静态资源由 nginx 直出

QQ 平台 ──HTTPS POST──> https://你的域名/qqbot/webhook
                              │  nginx（443 / TLS）
                              ▼
                    127.0.0.1:18900  webhook 接收端（Ed25519 验签 → 异步落库）
                    127.0.0.1:18901  面板 API
                              │
                              ▼
                     SQLite：群 / 成员 / 消息 / 规则 / 定时 / 处置 / 审计 / 原始事件

快速开始

三分钟起一个能收事件的实例

git clone https://github.com/cd1005-art/QQBOT.git
cd qqbot
python -m pip install -r requirements.txt
cp config.example.toml config.toml
# 或直接启动，首次访问会引导填写
python -m qqbot serve

启动后访问 http://127.0.0.1:18901/panel/，首次会进入初始化引导。

# Docker
docker run -d --name qqbot \
  -p 127.0.0.1:18900:18900 \
  -p 127.0.0.1:18901:18901 \
  -v $PWD/data:/app/data \
  -v $PWD/config.toml:/app/config.toml \
  ghcr.io/<you>/qqbot:latest

镜像里已包含 Python 运行时与依赖，配置与数据挂载到宿主机。
